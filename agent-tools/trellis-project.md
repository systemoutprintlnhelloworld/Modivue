# Modivue 开发规范

产品目标、实施约束、UI 要求、验证方式和工具分工，以根目录 `AGENTS.md` 为准。领域术语以根目录 `CONTEXT.md` 为准。

当前没有业务源码、确定的技术栈或构建命令。不要虚构示例实现、测试命令或已完成的功能。

需要 Trellis 管理的任务使用 `.trellis/tasks/`，不同时在 `.spec-workflow/` 维护相同任务。任务的要求和上下文引用上述文件。

执行任务时先查已有上下文，再完成当前明确范围。用户未主动要求时，不新增测试代码、不提交代码、不创建分支或 worktree。

本项目的初始化记录在 `agent-tools/README.md`。工具选用和开发流程见 `agent-tools/WORKFLOW.md`。安装文件、宿主注册、连接验证分别记录，不互相替代。
