# 校准档案

概率探针和校准模式 Juice 需要同条件档案。档案记录来源、版本、模型、推理档位、提示词、温度和输出上限。缺档案时只保存明确标注的原始观测。

在可信 API 配置中选择端点、协议、模型和采样参数，再进行采集。连接检查只验证模型目录，不能替代推理请求验证。采样会消耗提供方额度。

One Token 与 Astra 分布档案要求每题至少十个有效样本；导出不自动生成身份判定阈值。HLWY 的少量试采只能预览分布，低于五十个有效样本不作为完整判定。

比较时必须保持方法版本、协议和采样条件一致。导入文件不能仅因包含相同模型名称，就作为不同协议或推理档位的参考。

实现：[可信采集](../../src/core/trusted-calibration.mjs)、[分布档案导出](../../src/core/calibration-export.js)。方法来源见 [模型核验](verification.md)。
