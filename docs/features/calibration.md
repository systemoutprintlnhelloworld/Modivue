# 可信参考与校准

<!-- 来源：旧版 README 的 0.4.0、0.4.1 条目与"本地代理"中"可信 API 回答对照"段落。发布前请按当前代码核对 -->
![可信参考与校准](../assets/features/calibration.png)

分布类核验方法（One Token、Astra、HLWY、自定义概率探针、Juice 校准模式）需要一份参考：**同一个模型在可信渠道上，同样条件下回答的分布。** 这一页说明怎么采集这份参考、怎么保存和导入。

[返回 README](../../README.md#模型核验) · [功能索引](README.md)

## 什么算"同条件"

比较时以下条件必须一致，否则距离没有意义：

- 模型；
- 协议（Chat Completions / Responses / Messages）；
- 提示词；
- 采样参数与推理档位。

参考采样参数与监控目标的档位分别保存，便于核对。

## 方式一：可信 API 回答对照

在"设置"中找到"可信 API 回答对照"：

1. 填入可信渠道。Key 只用于本轮采集。
2. 先做 2 次试采样，确认请求正常。
3. 正式采集 16–100 次，可以随时停止。采样计入每日请求额度。
4. 完成后，在模型核验中选择"分布指纹"，核验相同模型、协议和推理档位的其他渠道。

## 方式二：从历史报告导出档案

适用于 One Token 和 Astra：

1. 在可信渠道运行核验，每题至少 10 次（默认每题 1 次只是预览）。
2. 核验完成后，在"历史核验报告"中导出分布档案。导出的档案会做 JSON 内容校验。
3. 在"设置 → 核验 → 核验校准档案"中导入。
4. 之后在其他渠道运行同一方法，即可与档案比较。

## 限制

- 自动采集和导出档案都**不会自动生成真伪阈值**。没有阈值时只显示距离。
- Astra 原帖没有公开精确题库和分布，Modivue 的参考只能自采。
- One Token 只适配英文 10 类任务，没有论文的四语言全集。
