# 费用与余额

费用按模型、provider、Key 分组。余额趋势只绘制成功的真实余额快照，并保留采样时间和样本数。没有历史点时，页面显示空数据提示，不补造折线。

| 费用状态 | 来源 |
|---|---|
| 实际 | 提供方明确返回的扣费 |
| 估算 | token 用量乘以可用价格 |
| 未知 | 无法取得费用或估价条件不足，不计作零 |

花费页按渠道和 Key 分组动态列出余额历史，不同单位分开绘图。历史窗口为最近七天；只有一个快照时只能显示单点，不补造趋势。失败查询不作为零余额写入历史。

在设置的余额配置中选择接口，填写需要的查询凭据、字段路径和单位。New API 账户查询与 Key 额度查询使用不同凭据；原始 quota 不能直接当作美元。满环比例使用总额度或已观察到的最高余额，充值后更新。
