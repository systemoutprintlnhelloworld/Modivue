## 余额

### 余额从哪里读

概览页会读取本机 CC Switch、已保存的可信渠道和 Agent 渠道的余额。支持的来源：

- OpenRouter；
- New API / Sub API；
- 常见的 `/v1/usage`、`/user/balance` 接口；
- 自定义 JSON 字段映射，用于其他格式的余额接口。

凭据只在本机使用。

### Codex 官方 OAuth 额度

Codex 使用官方 ChatGPT OAuth 登录时，Codex rollout 可能写入 `rate_limits`。Modivue 被动读取仍未过期的 5 小时（`300` 分钟）和 7 天（`10080` 分钟）窗口，按 `100% - used_percent` 显示剩余额度，并保留 Codex 提供的重置时间。

这不是 Provider 钱包余额，也不会发起额外请求。只有本地会话实际写入这些字段时才显示；自定义 API Key、旧记录和未转发 `rate_limits` 的中转服务显示“未提供”。额度语义以 [OpenAI Codex 使用限制文档](https://developers.openai.com/codex/cli/usage-limits) 为准。

### 在界面上怎么看

- **灵动岛：** 余额显示为环的外圈。首次读到的有效余额作为满环基准；充值后超过基准时环保持满格；可以在设置中重置基准。
- **概览页：** 显示当前渠道余额；"供应商余额"列出每个渠道的余额，可以配置余额接口或手动刷新。接口失败时直接显示错误，例如 HTTP 状态码，不会显示成 0。

## 检测花费

主动探测和模型核验都会向上游发请求，消耗的是你自己 Key 的额度。

- 每次核验逐请求记录花费；概览页显示所选模型的总花费、平均单次和最近单次；
- 拿不到价格时显示"未知"，不记为 0；
- 导出文件时使用系统保存窗口，导出完成会弹出提示。

### 控制主动探测的花费

主动探测默认开启。服务启动后，会按设置的间隔对正在运行的 Agent 目标采样；页面加载本身不会额外触发请求。

| 控制项 | 范围 |
|---|---|
| 开关 | 可随时暂停 |
| 采样间隔 | 1–1440 分钟 |
| 每日请求上限 | 手动采样同样计入 |
| 单次输出 token 上限 | 限制每次请求的输出长度 |

协议、Base URL、Key 分组、规范模型和请求方式都相同的目标只探测一次，不会重复计费。

## BazaarLink 的费用

以下内容来自 BazaarLink 官网说明，Modivue 未独立核实：

- [Probe API 说明](https://bazaarlink.ai/probe-api-skill.md)：不另收检测服务费，token 由目标 Key 计费。
- [BYOK 说明](https://bazaarlink.ai/solutions/byok)：使用自有上游时零加价；默认会无缝回退到平台路由，回退时按平台价格计费，开启严格模式可禁用回退。

官网自己控制内部探针的请求数。远程每日轮数与 Modivue 本地的请求预算分别计算。
