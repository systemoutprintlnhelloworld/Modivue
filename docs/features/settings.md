# 设置与通知

设置保存核验轮次、请求间隔、显示环、可见标签页和通知。模型核验、TTFT、Cache、请求失败与余额通知可以分别开关并选择音效。

## 检测间隔

核验轮次间隔控制两轮自动核验之间的等待，支持 1–1440 分钟。工作中请求间隔控制同一轮内部多个请求的让行时间，不替代轮次间隔。单问题每轮只有一次请求；需要每五分钟一次时设置轮次间隔为五分钟。BazaarLink 持续计划有独立调度设置。

## 通知

模型核验、TTFT、Cache 和请求失败可以各自启停；余额使用独立阈值和应用内、系统通知开关。五类事件各有静音或音效选择，同时受声音总开关和音量控制。关闭某类声音不等于关闭该类事件记录。

系统横幅需要操作系统授权。浏览器声音也受自动播放策略限制。Windows 托盘横幅可能使用系统默认声音，关闭应用音效不保证托盘横幅静音，这部分尚待 Windows 实机验收。

## 显示

设置可调整主题、文字大小、普通及专注形态的环、非必要标签页。版本信息位于设置；模型目录同步信息位于模型页。上下文检测环、指标定时播报尚未开发。
