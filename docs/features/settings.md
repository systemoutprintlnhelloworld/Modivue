## 设置页怎么用

- 设置按横向分类排列，顶部可以搜索设置项。
- 修改后自动保存，保存成功会弹出提示。
- 输入超出范围时会提示；保存失败时保留你填的草稿，不会被刷新覆盖。

## 检测

| 设置 | 说明 |
|---|---|
| 主动探测 | 开关；关闭后暂停自动采样 |
| 采样间隔 | 1–1440 分钟 |
| 每日请求上限 | 手动采样同样计入 |
| 单次输出 token 上限 | 限制每次探测请求的输出长度 |
| 可信 API 回答对照 | 见 [可信参考与校准](calibration.md) |
| 核验校准档案 | 导入分布档案，见 [可信参考与校准](calibration.md#方式二从历史报告导出档案) |

费用相关说明见 [费用与余额](cost.md)。

## 通知

- 系统通知由常驻的灵动岛发出，设置中可以发送一条测试通知。
- 可以按告警类别设置不同音效。

## 外观与语言

| 设置 | 说明 |
|---|---|
| 语言 | 首次启动跟随系统语言，也可以手动切换中文或英文；题目原文与模型回答保留原始语言 |
| 主题 | 强调文字与边框跟随主题；macOS 原生标题栏同步应用主题 |
| 文字大小 | 80%–200% |
| 正文文字颜色 | 任何主题下都可以单独设置 |
| 显示项 | 选择要显示的指标与信息 <!-- 说明：补充具体选项 --> |
| 环的对比度 | 调整模型底色与空环的对比度 |
| 余额基准 | 重置余额环的满环基准，见 [灵动岛](island.md#余额环的满环基准) |

系统开启"减少动态效果"时，面板动画遵循系统设置。
