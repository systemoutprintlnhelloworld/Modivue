# 模型核验

<!-- 来源：README；旧版 README 的 0.2.0–0.4.1 条目与"本地代理"条目。请求量等数字请按当前版本核对 -->
![模型核验](../assets/features/verification.png)

模型核验回答的问题是：**这个渠道返回的模型，行为是否和参考一致。** 结果是行为证据，不是人类 IQ，不是 coding 能力分数，也不是模型身份认证。

[返回 README](../../README.md#模型核验) · [功能索引](README.md) · [原理与局限](../../MODEL-VERIFICATION.md)

## 开始一次核验

1. 在主窗口进入"模型核验"，选择要核验的对象（模型 × 渠道 × Key 分组 × 推理档位）。
2. 选择方法。不知道选哪个时，参考 [README 中的选择表](../../README.md#先按你的情况选方法)。
3. 开始检测。Agent 正在工作时会先排队，空闲后开始，界面显示有效样本数和阶段进度。
4. 完成后在"历史核验报告"中查看。历史报告可以跨方法查看，每份报告都保留原始回答。

核验会向上游发请求并消耗 token，花费逐请求记录，见 [费用与余额](cost.md)。

## 各方法说明

### 单问题测试

使用你自己的题目和参考答案。每轮只发一次请求，并复用这次请求的 TTFT、Cache 和用量记录。默认上一轮完成后 60 秒再测，可设 5–3600 秒。统计按题目内容版本和四元组隔离，计算时间窗口内的匹配数、有效比对数、比例、失败次数和总次数；超过 5000 条也完整计数。

水杯等内置单题默认超时 300 秒、最多输出 16384 token；水杯证明题不限时，可以手动暂停或终止，完整原始回答保留供人工复核。

### Meow 模型指向

通过短答案分布，判断待测 API 更接近候选池中的哪个模型。基于上游 [meow-llm-detector](https://github.com/chen-006/meow-llm-detector) 4.5.4 正式基准，支持 Responses、Messages 与 Chat Completions。

| 档位 | GPT 候选 | Claude 候选 |
|---|---|---|
| 预览 | 6 次请求 | 6 次请求 |
| 完整三档 | 32 / 48 / 96 次 | 48 / 72 / 120 次 |

候选命中与原始分数分开展示。另收录 7727 条 OpenRouter 可信端样本（17 个模型、16 道题），仅用于展示参考频数；评分参数与阈值仍使用上游正式版。

### KBF 知识边界

对照 16 个公开历史模型的参考，共 4359 个探针。可以先试采一批，但试采结果不下完整结论；完整结论使用 CP99 / 单侧二项检验。

### HLWY 分布匹配

比较公共整数分布的众数、余弦和 JS 相似度。参考可以用公共分布，也可以用可信 API。少于 50 个有效样本时只算预览。

### One Token 与 Astra

- **One Token：** 单 token 英文任务的分布差异，适配 10 类英文任务，没有复现论文的四语言全集。
- **Astra：** 适配社区原帖的五组任务。原帖没有公开精确题库和分布，Modivue 不输出原帖那种强指向结论。

两者默认每题 1 次，只作预览。要做有效对照，需先在可信渠道采集参考档案，见 [可信参考与校准](calibration.md)。

### 自定义概率探针

比较自定义短答案分布的 JSD 距离。没有同条件校准档案时只显示距离，不给判定。

### Juice

记录生成答案中的原始整数，只作为证据保存。它不是服务器认证的预算。没有可信候选校准时标记为证据不足。

### BazaarLink Probe

接入官方异步 API。每个四元组单独授权，发送 Key 前会显示说明。

- 支持快速、综合、上下文三种模式；
- 支持持续检测：设置间隔和每日轮数，显示进度，可以停止；
- 报告持久化；应用重启后继续读取原检测任务，启动时无法确认状态则暂停续测；
- 运行中的报告不作为完成结果导入。

逐题结果不会合成为 IQ，报告签名也不视为模型身份认证。费用说明见 [费用与余额](cost.md#bazaarlink-的费用)。

### Ztest

提供两个独立入口：

- **官方检测：** 在 Ztest 官网完成检测（包括人机验证），再用报告 URL 或 JSON 导入。Modivue 不在后台代填凭据，也不绕过人机验证。导入时保存探针明细和原始报告；关联到四元组前需要确认归属；同一份报告重复导入不会重复记账。
- **本地多探针：** 五组简单请求，记录回答、失败和耗时。它不复刻 Ztest 的私有探针，也不冒充官网评分。

## 边界

- 匹配度不等于身份置信度。
- 自动采集不设置真伪阈值。
- 未知费用显示为"未知"，不记为 0。
