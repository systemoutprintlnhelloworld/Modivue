# 概览与指标趋势

概览按模型、渠道、Key 分组和推理档位展示指标。余额在同一趋势图中单独绘制，使用对应渠道的余额快照，不与模型请求混算样本数。

数据来自本地 SQLite。真实字段缺失时显示缺失状态，不根据耗时猜 Cache，也不把未知费用写成零。

| 指标 | 单位与口径 |
|---|---|
| Cache | 缓存读取 token / 输入 token；上游未返回字段时为缺失 |
| TTFT | 毫秒或秒；请求发出到首个有效文本或工具输出 |
| 核验 | 由当前方法决定，不能将整数观测和百分比混为同一量纲 |
| 余额 | 提供方返回的币种或额度单位，使用独立纵轴 |

选择目标和时间范围后查看曲线。图例可隐藏或显示某条线；点击数据点进入对应指标页。余额历史最多保留七天，请求样本数和余额快照数分别显示。

## 布局

长按区块非交互区域约 420 毫秒进入排序，继续按住即可拖动。按钮、链接、输入框和图表保留原操作。释放保存顺序；Escape 取消本次移动。系统或应用启用减少动态效果时，不播放排列抖动。

实现：[趋势绘制与布局入口](../../app.js)、[布局状态](../../src/core/dashboard-layout.js)。
