灵动岛是一条贴在屏幕边缘的竖向悬浮条。写代码时它保持极简，需要时再展开。

[返回 README](../../README.md#悬浮窗) · [功能索引](README.md)

## 三种形态

<!-- 说明：请确认"普通态"是否对应"鼠标移入后的 Agent 面板" -->

| 形态 | 怎么进入 | 显示什么 |
|---|---|---|
| 极简态 | 默认 | 每个活跃模型一个环，环心为模型图标，外圈为余额；拖条与设置按钮隐藏 |
| 普通态 | 鼠标移入 | 显示监测目标，拖条与设置按钮平滑恢复 |
| 专注态 | 悬停单个环 | 展开指标与详情卡片 |
| 闲置 | 没有活动时 | 显示状态图标 |

## 专注态的内容

悬停模型后，悬浮条纵向显示四个环：**模型核验、Cache、TTFT、余额**。浮窗同时向左展开一张详情卡片，内容包括：

- 模型名、渠道、Key 短指纹、推理档位；
- 关联的 Agent 及其状态（已打开 / 待命）；
- 模型核验、Cache、TTFT 三项数值和最近 1 小时曲线；
- 渠道余额、性能样本数、核验费用。

环上暂时没有数值时显示 `--`，完整状态在详情卡片中查看。

## 余额环的满环基准

首次读到的有效余额作为满环基准。充值后余额超过基准时，环保持满格。可以在设置中重置基准。

## 操作

- **拖动与吸附：** 拖动悬浮条，靠近屏幕左右边缘时自动吸附。
- **打开主窗口：** 点击模型，打开对应的统计窗口。
- **关闭窗口不退出监测：** macOS 上关闭统计窗口后，可以从菜单栏的波形图标重新打开窗口、恢复灵动岛或退出，也可以使用右键菜单。Windows 上通过托盘恢复窗口或退出。
- **系统通知：** 通知由常驻的灵动岛发出，见 [设置与通知](settings.md)。

## 动效与外观

- 指标图标内有 SVG 动画，只在悬停时播放；从普通态进入专注态时环会高亮。
- 系统开启"减少动态效果"时，这些动画遵循系统设置。
- 模型底色和空环的对比度可以在设置中调整。

## 平台差异

- **macOS：** 原生窗口承载灵动岛，悬停后原生浮窗向左扩展。
- **Windows：** 支持悬停、拖动和左右吸附；原生鼠标交互与多 DPI 显示的实机验收尚未完成。
