# Documentation media

[中文](../media.md) · [Back to README](../../README.en.md#documentation)

Shared media lives under `docs/assets/`. Both README languages reference the same files; screenshots currently show the Chinese interface.

## Publication checks

Before publishing screenshots or recordings, check for credentials, private provider domains, key fingerprints, balances, and conversation content. Remove accidental selections and capture-tool watermarks. Do not label an illustration as an application screenshot or assume an existing image is anonymized without reviewing it.

## Replacement

Replace a file in place to update both languages. If its extension or location changes, update all README and feature-guide references. Keep a consistent aspect ratio for grid thumbnails. Feature pages reference these same assets directly. Missing or unreviewed media should remain explicitly identified, not silently presented as validated screenshots.
