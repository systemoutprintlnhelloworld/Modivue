# Settings and notifications

Settings are grouped horizontally and saved automatically. Invalid values remain in the draft and show an error.

## Detection

Configure active probing, a 1–1440 minute interval, daily request limit, output-token limit, trusted API collection, and verification calibration archives.

## Notifications

The resident Dynamic Island can send system notifications and a test notification. Alert categories can use separate enable switches and sounds.

## Appearance and language

Choose Chinese or English, theme, text size, body text color, visible metrics, ring contrast, and the balance full-ring reference. Reduced-motion settings are respected.
