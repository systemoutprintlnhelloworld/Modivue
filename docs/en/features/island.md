# Dynamic Island panel

The Dynamic Island is a vertical panel attached to the screen edge. It stays compact until you need more detail.

| State | Entry | Content |
|---|---|---|
| Minimal | Default | Active model rings and balance |
| Normal | Hover the panel | Active targets and controls |
| Focus | Hover one ring | Verification, cache, TTFT, balance, and trends |
| Idle | No active target | Status icon |

The panel can be dragged and snaps to the nearest screen edge. Click a model to open its statistics window. Metric SVG animation plays on hover and follows reduced-motion settings.
